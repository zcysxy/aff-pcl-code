# Project: Experiments for AffPCL

## Project Structure

- `ref/` contains reference papers for each algorithm. Use them as descriptions to implement the algorithms.
- `main.py` is the main and only script to run experiments. Implement your code in this file.

## General Instructions

- Please follow the existing coding style in `main.py`.
- The existing code already has the setup and data generation parts. Do not modify the setup and data generation code. You only need to implement the algorithms and run the experiments.
